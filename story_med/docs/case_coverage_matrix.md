# Case 覆盖矩阵说明

## 1. 说明

- 本文档用于说明 `story_cases.md` 当前 19 条测试样本的覆盖范围与排序原则。
- 排序遵循：`标准 Case -> 异常 Case`，组内再按药物 / 治疗类型聚合，便于批量回归和定向挑选案例。
- 这里的“异常 Case”不等同于病例本身异常，而是指其验证目标更偏向边界条件、复杂链路、合规陷阱、罕见病或提示词鲁棒性。

## 4. 按药物 / 治疗类型覆盖

- 靶向药：奥希替尼、奥拉帕利、阿来替尼、洛拉替尼，以及多线 EGFR 靶向 / 双抗试验场景。覆盖早期辅助、维持治疗、耐药换药、寡进展和多线压缩。
- PD-1 / 免疫治疗：帕博利珠单抗、替雷利珠单抗、信迪利单抗，覆盖联合化疗、单药治疗、再挑战、维持治疗、高龄不耐受顺铂、严重 irAE、适应症合规陷阱。
- ADC：T-DXd 新辅助场景，覆盖 pCR 表达边界与 ADC 图片设计合理性。
- GLP-1：司美格鲁肽、替尔泊肽、HRS-7535 及泛 GLP-1 场景，覆盖慢病代谢改善、罕见病复杂代谢、心理行为改变、依从性提升。
- 化疗 / 内分泌 / 手术：XELOX、AC 方案、来曲唑、肺叶切除术、乳癌改良根治术等，覆盖标准术后辅助与联合治疗叙事。
- 非肿瘤生物制剂：伊奈利珠单抗，覆盖系统对非肿瘤免疫性疾病的适配能力。

## 5. 按疾病覆盖

- 肿瘤疾病：肺腺癌、肺鳞癌、胃癌、乳腺癌、卵巢癌、膀胱尿路上皮癌、肝细胞癌、肾透明细胞癌。
- 非肿瘤疾病：NMOSD、2 型糖尿病、肥胖症、进食障碍、Alström 综合征、MASLD。
- 既覆盖实体瘤主流患者故事，也覆盖慢病管理、心理行为、罕见病和非肿瘤适配场景。

## 8. 当前矩阵的价值

- 适合先用标准 Case 验证“主链路可用性”和图片 / 长图基本质量，再用异常 Case 打边界。
- 适合按药物组回归，例如只回归 GLP-1、只回归 PD-1，减少提示词改动后的无效重跑。
- 适合按风险主题选样，例如只看合规坑、只看 irAE、只看极简输入。

## 9. 可继续补的空白

- 儿科 / 青少年肿瘤病例仍较少。
- 血液肿瘤、ADC 毒性更复杂场景、真实放疗主导病例还可以补充。
- 妊娠、围手术期 ICU、终末期缓和医疗等高情绪 / 高风险场景还没有覆盖。
- 多民族 / 多地域文化背景的患者叙事样本仍可扩展。
